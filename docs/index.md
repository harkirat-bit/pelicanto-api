# Pelicanto documentation

Pelicanto is a transactional email API. You send a message with one HTTP request, we handle delivery, retries, and tracking, and you get webhooks when something happens to the message.

![Dashboard overview](images/dashboard-overview.png)

## Start here

- [Getting started](getting-started.md): send your first message in five minutes.
- [Authentication](authentication.md): API keys, environments, and key rotation.
- [Sending email](sending-email.md): raw HTML, plain text, and templated sends.
- [Templates](templates.md): reusable layouts with variables.
- [Webhooks](webhooks.md): delivery, bounce, open, and complaint events.
